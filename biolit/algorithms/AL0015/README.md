## 科学边界

- 正文§2未来标签终点有笔误，本稿采用§3的C+H定义。
- 正文历法分母P与算法2的P−1不一致，保留两段原文，不默默统一。
- Hann处理按算法原文写卷积，其边界模式仍需固定代码实现核验。
- 算法3频率公式的单位是每采样点周期数，与旁注“normalized to Nyquist”有差异。
- 97任务主基准、78任务骨干比较、81任务特征消融不是相同样本集合。
- fev原30项未来协变量任务中2项超过6小时，28项进入最终报告。TabPFN-TS是比较中唯一直接使用协变量的模型。
- 趋势失败是实验观察及作者的机制解释，不是输出分布严格限于历史值域的数学定理。
- 较低WQL不能单独证明所有条件下的校准，逐时刻区间不等于整条路径同时覆盖。
- 未执行训练或基准复现，没有将中文手算当成真实预测记录。
