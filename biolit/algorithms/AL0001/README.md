# AL0001 · TabPFN teaching bundle

This bundle contains a 198-slide Chinese teaching presentation about *Accurate predictions on small data with a tabular foundation model*.

## Open the presentation

Open `deck.html` in a modern browser. Keep the accompanying `assets/` directory beside `deck.html`. The HTML and 196 figure PNGs exactly match the accepted presentation. Download the repository ZIP (Code → Download ZIP), extract it, then open `biolit/algorithms/AL0001/deck.html` for offline reading. Do not download the HTML alone. Use the on-screen controls or arrow keys to navigate. The “演示模式” button switches to presentation mode.

The accepted font declarations are unchanged: Noto Sans CJK SC, Microsoft YaHei, and sans-serif fallback. Fonts are not bundled. Appearance can differ on computers without the same fonts. The browser's print control is retained, but this bundle does not include a PDF because a native print export was unavailable and has not been verified.

## Changes and reuse

This teaching adaptation adds Chinese explanation, interpretation, explicitly labelled teaching derivations and research questions. It crops, enlarges, splits, and arranges source excerpts, figures, and tables for slide-based teaching. Source references remain visible in the slides. This source bundle preserves the accepted HTML and original PNG bytes exactly. It does not alter slide text, CSS, scripts, or font declarations.
